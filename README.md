# Tienda Elegance

Bienvenido a la tienda **Elegance**, un sitio web moderno y elegante para explorar y comprar productos de moda para hombres, mujeres y accesorios. Este proyecto está diseñado para ofrecer una experiencia de usuario intuitiva y atractiva.

## Estructura del Proyecto

El proyecto está organizado de la siguiente manera:

- **index.html**: Página principal de la tienda Elegance. Aquí encontrarás una introducción a la tienda, destacados y enlaces a las demás secciones.
- **hombres.html**: Página dedicada a la moda masculina. Explora nuestra colección de ropa y accesorios para hombres.
- **mujeres.html**: Página dedicada a la moda femenina. Descubre las últimas tendencias en ropa y accesorios para mujeres.
- **accesorios.html**: Página de accesorios. Encuentra complementos perfectos para completar tu look.
- **contacto.html**: Página de contacto. Ponte en contacto con nosotros para consultas, soporte o colaboraciones.

### Carpeta de Imágenes

Todas las imágenes utilizadas en el sitio web se encuentran en la carpeta `images`. Esta carpeta contiene:

- Imágenes de productos.
- Logotipos y gráficos de la tienda.

## Cómo Navegar

1. **Página Principal (`index.html`)**: Comienza en la página principal para obtener una visión general de la tienda y acceder rápidamente a las diferentes secciones.
2. **Moda Masculina (`hombres.html`)**: Haz clic en el enlace "Hombres" en el menú de navegación para explorar la colección masculina.
3. **Moda Femenina (`mujeres.html`)**: Haz clic en el enlace "Mujeres" en el menú de navegación para descubrir la colección femenina.
4. **Accesorios (`accesorios.html`)**: Haz clic en el enlace "Accesorios" para ver nuestra selección de complementos.
5. **Contacto (`contacto.html`)**: Si necesitas ayuda o quieres ponerte en contacto con nosotros, visita la página de contacto.

## Tecnologías Utilizadas

- **HTML5**: Para la estructura y contenido del sitio web.
